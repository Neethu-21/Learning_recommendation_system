# Adaptive Learning Recommendation & Performance Analytics System

## Overview

An intelligent student performance analytics platform that evaluates academic performance, predicts future scores, identifies weak subjects, and generates personalized learning recommendations based on career goals and study availability.

## Features

* Student Performance Dashboard
* Subject-wise Trend Analysis
* Weak Subject Detection
* Risk Level Assessment
* Score Prediction using Linear Regression
* Personalized Learning Recommendations
* Career Goal-Based Learning Paths
* Study Time-Based Adaptive Roadmaps
* Learning Mentor Guidance
* SQLite Database Integration
* Recommendation History Tracking
* PDF Notes and Learning Resources

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* SQLite

## Project Structure

* app.py – Streamlit User Interface
* analyzer.py – Student Performance Analysis
* model.py – Score Prediction and Risk Assessment
* recommender.py – Recommendation Engine
* mentor.py – Learning Mentor Module
* database.py – SQLite Database Operations

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

streamlit run app/app.py
